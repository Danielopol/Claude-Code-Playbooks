# Literature Review System

## Workflow Phases

### Phase 1: Define Scope
Before searching:
1. State the research question clearly
2. Define inclusion/exclusion criteria
3. Identify key terms and synonyms
4. Specify date range and source types

### Phase 2: Search & Collect
Search strategy:
1. Generate search queries from key terms
2. Search multiple databases if available
3. Track sources in a structured format
4. Apply inclusion/exclusion criteria

### Phase 3: Extract & Analyze
For each paper, extract:
- **Citation**: Full reference
- **Research Question**: What are they investigating?
- **Methodology**: How did they study it?
- **Key Findings**: What did they find?
- **Limitations**: What are the caveats?
- **Relevance**: How does this connect to our question?

### Phase 4: Synthesize
Combine extractions into:
- Thematic groupings
- Points of agreement/disagreement
- Evolution of the field
- Identified gaps
- Future directions

## Paper Analysis Template

```markdown
## Paper: [Short Title]

**Citation**: [Full citation]
**Year**: [Year]
**Type**: [Empirical/Theoretical/Review/etc.]

### Research Question
[What question does this paper address?]

### Methodology
[How did they study it? Sample, methods, analysis]

### Key Findings
1. [Finding 1]
2. [Finding 2]
3. [Finding 3]

### Limitations
- [Limitation 1]
- [Limitation 2]

### Relevance to Our Review
[How does this connect to our research question?]

### Key Quotes
> "[Direct quote if particularly relevant]" (p. X)
```

## Synthesis Matrix

Track themes across papers:

| Paper | Theme A | Theme B | Theme C | Methods | Findings |
|-------|---------|---------|---------|---------|----------|
| Smith 2020 | ✓ | - | ✓ | Survey | X > Y |
| Jones 2021 | ✓ | ✓ | - | Experiment | X = Y |
| Lee 2022 | - | ✓ | ✓ | Interview | X < Y |

## Commands

- `/lit-review [topic]` — Start a new literature review
- "Analyze this paper: [citation/pdf]" — Extract from single paper
- "Synthesize papers on [theme]" — Combine extractions
- "Find gaps in the literature" — Identify what's missing
- "Write the introduction section" — Draft based on synthesis

## Output Formats

### Annotated Bibliography
```
1. Smith (2020): [2-3 sentence summary focusing on contribution and relevance]

2. Jones (2021): [2-3 sentence summary...]
```

### Thematic Review
```
## Theme 1: [Name]
[Paragraph synthesizing what multiple papers say about this theme]

## Theme 2: [Name]
[Paragraph synthesizing...]
```

### Gap Analysis
```
## What We Know
[Summary of established findings]

## What We Don't Know
[Identified gaps and unanswered questions]

## Why It Matters
[Significance of the gaps]
```
