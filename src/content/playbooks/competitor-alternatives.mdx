## What This Does

Creates competitor comparison and alternative pages that rank for competitive search terms and provide genuine value to evaluators. Covers four formats — singular alternative, plural alternatives, you vs competitor, and competitor vs competitor — with centralized competitor data so updates propagate everywhere.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/competitor-pages`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Describe your product, target competitors, and page goals.

## Inputs You'll Need

- **Your product** — value prop, differentiators, ICP, pricing, honest weaknesses
- **Competitive landscape** — direct and adjacent competitors, search volume for competitor terms
- **Goals** — SEO traffic, sales enablement, conversion from competitor users, brand positioning

## How It Works

1. Build a centralized competitor profile (positioning, pricing, feature ratings, strengths/weaknesses, common complaints, migration notes)
2. Choose page format(s) based on search intent
3. Write honest, depth-over-surface comparison copy
4. Add TL;DR, comparison tables, paragraph comparisons, migration sections, and CTAs
5. Plan internal linking and FAQ schema
6. Define refresh cadence (quarterly verification + annual full review)

## What You Get

- Centralized competitor data file (YAML)
- Full page copy for each format with sections, tables, and CTAs
- Page set plan ordered by search volume
- Migration section templates
- SEO and schema recommendations

## Tips & Best Practices

- **Honesty builds trust** — acknowledge competitor strengths; readers will verify claims
- **Depth over surface** — explain *why* differences matter, not just what they are
- **Be explicit about who each tool is best for** — even when it's not you
- **Update quarterly** — stale competitor data breaks trust fast
