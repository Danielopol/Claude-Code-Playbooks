## What This Does

Takes a list of competitor URLs and produces structured competitor profile documents by combining live site scraping with SEO and market data. The output is reusable across competitor comparison pages, sales battle cards, and positioning work.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/competitor-profiling`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Provide a list of competitor URLs and a depth level (quick scan or deep profile).

---

## Inputs You'll Need

- **Competitor URLs** — list of competitor websites to profile
- **Your product** — what you do, for context
- **Depth level** — quick scan (key facts only) or deep profile (full research)
- **Focus areas** — pricing, positioning, SEO strength, content strategy

## How It Works

1. Scrape each competitor site for positioning, pricing, features, content
2. Pull SEO data (domain rating, top pages, top keywords, traffic estimates)
3. Mine reviews from G2, Capterra, TrustRadius for common complaints and praise
4. Document strengths, weaknesses, ideal customer, and migration notes
5. Build a structured profile per competitor in markdown/YAML

## What You Get

- One markdown profile file per competitor with consistent sections
- Positioning, pricing, and feature inventory
- SEO snapshot
- Review-mined customer feedback (themes and quotes)
- Strengths, weaknesses, "best for" / "not ideal for"
- Hooks for downstream use in comparison pages and battle cards
