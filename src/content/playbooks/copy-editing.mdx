## What This Does

Systematically improves existing copy through focused editing passes that preserve the core message. Each pass focuses on one dimension — clarity, specificity, voice, conversion — catching issues a single review would miss.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/copy-editing`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Paste the copy you want edited and describe the page type and audience.

---

## Inputs You'll Need

- **The copy to edit** — page, section, or asset text
- **Page purpose and audience** — what action it should drive, who reads it
- **Brand voice** — tone, vocabulary, level of formality
- **What's working** — anything you want preserved

## How It Works

1. **Pass 1: Clarity** — eliminate jargon, ambiguity, and bloat
2. **Pass 2: Specificity** — replace vague claims with concrete proof
3. **Pass 3: Voice & rhythm** — align to brand voice, vary sentence length
4. **Pass 4: Conversion** — sharpen CTAs, headlines, and decision points
5. **Pass 5: Mechanics** — typos, grammar, formatting consistency
6. Track each change with a brief rationale

## What You Get

- Edited copy with tracked changes and reasoning
- Before/after version showing improvements
- Voice and consistency notes for the team
- Optional content audit if multiple pages are reviewed

## Tips & Best Practices

- **Don't change the core message** — focus on enhancing it
- **Multiple focused passes beat one unfocused review**
- **Each edit should have a clear reason** — no changes for the sake of change
- **Preserve the author's voice** while improving clarity
