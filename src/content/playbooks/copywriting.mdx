## What This Does

Writes marketing copy that is clear, compelling, and drives action — for homepages, landing pages, pricing pages, feature pages, about pages, and product pages.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/copywriting`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Describe the page type, audience, and one primary action you want.

---

## Inputs You'll Need

- **Page type and goal** — homepage, landing page, pricing, etc., and the ONE primary action
- **Audience** — ICP, problems they're trying to solve
- **Product details** — what it does, what's different, proof
- **Constraints** — brand voice, must-haves, length limits
- **Existing copy** — for context if rewriting

## How It Works

1. Define the one primary action and the audience reading the page
2. Build the value proposition (problem, solution, differentiator)
3. Draft the hero (headline, subheadline, CTA, optional visual)
4. Outline supporting sections (proof, features, social proof, objections, FAQ)
5. Write each section with clarity and specificity
6. Review for one-page rhythm — no friction between scroll and CTA
7. Produce alternative variations for testing key sections

## What You Get

- Full page copy with hero and supporting sections
- 2–3 variations for headline and CTA
- Hierarchy of proof (testimonials, stats, logos, case studies)
- FAQ addressing the most common objections
- Notes on layout cues for design handoff
