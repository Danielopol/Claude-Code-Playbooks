## What This Does

Turns Claude into a multi-platform content strategist who takes one piece of content and reconstructs it as platform-native versions for every channel you publish on. Not reformatting — reimagining. Each version feels like it was born on that platform.

This is **Part 9 of 10** in the Content Swipe File System series by @hooeem.

---

## Why This Works

One great piece should work everywhere. This protocol:

- **Extracts the core insight** — Identifies the single idea worth spreading
- **Rebuilds for each platform** — Not shorter copies, but native reconstructions
- **Preserves full value** — Each version is independently valuable, not a teaser
- **Includes a posting schedule** — Staggered across 7-14 days for maximum reach

## Platform Adaptation Guide

| Platform | Style | Optimal Length | Key Adaptation |
|----------|-------|---------------|----------------|
| **Twitter/X** | Punchy, opinionated, thread-friendly | 280 chars/tweet | First tweet must stand alone |
| **LinkedIn** | Professional but personal, generous spacing | 1,200-1,500 chars | Paragraph-based, relatable |
| **Instagram** | Visual-first, conversational captions | Carousel: 5-10 slides | Content supports the visual |
| **YouTube** | Conversational, retention-optimised | Hook in first 5 seconds | Designed for watch time |
| **Newsletter** | Intimate, long-form friendly | Variable | Personal tone, depth allowed |
| **Blog/SEO** | Thorough, structured, searchable | 1,000-2,000+ words | Headers, subheaders, keywords |
| **TikTok/Reels** | Fast-paced, personality-driven | 30-90 seconds | Pattern interrupt in first 2s |

## Tips for Best Results

1. **Don't copy-paste across platforms** — Each version should feel native. A LinkedIn post is not a long tweet.
2. **Lead with your strongest platform** — Post the "anchor" version first, then repurpose outward
3. **Stagger posts across 7-14 days** — Never post the same idea on multiple platforms the same day
4. **Provide platform-specific context** — "My newsletter audience is more advanced than my Twitter followers" helps Claude adapt

## Troubleshooting

**Versions feel like reformatted copies**
Tell Claude: "Reimagine this for [platform] as if it was born there. Don't just shorten it."

**A platform doesn't fit the content**
Claude will flag when content is a poor fit for a platform and recommend skipping it.

**Followers see the same thing everywhere**
Each version should feel like a fresh perspective. If they don't, Claude needs to differentiate the angle, not just the format.
