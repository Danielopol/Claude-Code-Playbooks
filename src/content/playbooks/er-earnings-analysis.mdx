## What This Does

Generates institutional-quality earnings update reports (JPMorgan, Goldman Sachs, Morgan Stanley format) for companies already under coverage. Focuses on what's NEW — beat/miss analysis, key metrics, updated estimates, and revised thesis. Designed for 24-48 hour turnaround after earnings.

---

## Quick Start

### Step 1: Create a Project Folder

Create a folder for the company's earnings analysis and place the downloaded template inside as `CLAUDE.md`.

### Step 2: Download the Template

Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

### Step 3: Start Working

```
"Create an earnings update for Tesla Q3 2024"
"Analyze Apple's quarterly results"
"Post-earnings report for Microsoft"
```

## Output Specifications

| Spec | Details |
|------|---------|
| Length | 8-12 pages |
| Word Count | 3,000-5,000 words |
| Tables | 1-3 summary tables |
| Charts | 8-12 figures |
| Format | DOCX with Times New Roman |
| Turnaround | 1-2 days |

## Key Differences from Initiation Reports

Earnings updates are 8-12 pages (vs. 30-50 for initiations), focus only on what's new, use 1-3 summary tables (vs. 12-20), and assume the reader already knows the company.

## Dependencies

- Python (matplotlib, pandas, seaborn) for chart generation
- DOCX creation capabilities for the final report
