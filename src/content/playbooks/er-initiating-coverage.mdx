## What This Does

Produces comprehensive first-time coverage reports following institutional standards (JPMorgan, Goldman Sachs, Morgan Stanley format) through 5 sequential tasks: Company Research, Financial Modeling, Valuation Analysis, Chart Generation, and Report Assembly.

---

## Quick Start

### Step 1: Create a Project Folder

Create a folder structure for the full initiation workflow:
```
ProjectFolder/
  Task1_Research/
  Task2_Model/
  Task3_Valuation/
  Task4_Charts/
  Task5_Report/
```

### Step 2: Download the Template

Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

### Step 3: Start Working

Execute tasks one at a time:
```
"Do Task 1 for Tesla — Company Research"
"Do Task 2 for Tesla — Financial Modeling"
"Do Task 3 for Tesla — Valuation Analysis"
"Do Task 4 for Tesla — Chart Generation"
"Do Task 5 for Tesla — Report Assembly"
```

## The 5-Task Workflow

| Task | Name | Output | Dependencies |
|------|------|--------|-------------|
| 1 | Company Research | 6-8K word document | None |
| 2 | Financial Modeling | Excel model (6 tabs) | None |
| 3 | Valuation Analysis | Price target + Excel tabs | Task 2 |
| 4 | Chart Generation | 25-35 PNG charts | Tasks 1, 2, 3 |
| 5 | Report Assembly | 30-50 page DOCX | All previous |

## Final Report Specifications

- **Length**: 30-50 pages (minimum 30)
- **Word count**: 10,000-15,000 words
- **Charts**: 25-35 embedded images
- **Tables**: 12-20 comprehensive tables
- **Format**: Professional DOCX with clickable hyperlinks

## Important Notes

- Tasks must be executed one at a time for quality control
- Tasks 1 and 2 can run in either order; Tasks 3-5 have strict dependencies
- Each task verifies prerequisites before starting
- The final report should be indistinguishable from institutional research
