## What This Does

Produces comprehensive first-time coverage reports following institutional standards (JPMorgan, Goldman Sachs, Morgan Stanley format) through 5 sequential tasks: Company Research, Financial Modeling, Valuation Analysis, Chart Generation, and Report Assembly.

---

## Quick Start

### Step 1: Create a Project Folder

Create a folder structure for the full initiation workflow:
```
ProjectFolder/
  Task1_Research/
  Task2_Model/
  Task3_Valuation/
  Task4_Charts/
  Task5_Report/
```

### Step 2: Download the Template

Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

### Step 3: Start Working

Execute tasks one at a time:
```
"Do Task 1 for Tesla — Company Research"
"Do Task 2 for Tesla — Financial Modeling"
"Do Task 3 for Tesla — Valuation Analysis"
"Do Task 4 for Tesla — Chart Generation"
"Do Task 5 for Tesla — Report Assembly"
```

## The 5-Task Workflow

| Task | Name | Output | Dependencies |
|------|------|--------|-------------|
| 1 | Company Research | 6-8K word document | None |
| 2 | Financial Modeling | Excel model (6 tabs) | None |
| 3 | Valuation Analysis | Price target + Excel tabs | Task 2 |
| 4 | Chart Generation | 25-35 PNG charts | Tasks 1, 2, 3 |
| 5 | Report Assembly | 30-50 page DOCX | All previous |

## Final Report Specifications

- **Length**: 30-50 pages (minimum 30)
- **Word count**: 10,000-15,000 words
- **Charts**: 25-35 embedded images
- **Tables**: 12-20 comprehensive tables
- **Format**: Professional DOCX with clickable hyperlinks

## Important Notes

- Tasks must be executed one at a time for quality control
- Tasks 1 and 2 can run in either order; Tasks 3-5 have strict dependencies
- Each task verifies prerequisites before starting
- The final report should be indistinguishable from institutional research

## Running It Well: Task by Task

**Task 1 (Company Research).** Give Claude the latest 10-K, the most recent two or three earnings call transcripts and the investor presentation as files in `Task1_Research/`. With primary documents in hand, the management bios, segment descriptions and risk section come from what the company actually said instead of general knowledge. Ask for a source list at the end and spot-check it.

**Task 2 (Financial Modeling).** This is where errors creep in. Before moving on, ask Claude to tie the model back to the filings: historical revenue, net income and ending cash in the model should match the 10-K to the dollar. The template's rule that every number is "verified and cross-checked" only holds if you make that check an explicit step.

**Task 3 (Valuation).** The price target is only as good as the WACC and terminal growth assumptions behind it. Ask Claude to list every assumption in a table with its source, then look at the DCF sensitivity grid before accepting the base case. If a 50 bp change in WACC moves the target 30%, the report should say so.

**Task 4 (Charts).** Some of the 25–35 charts need data that isn't in your model, like share-price history, peer multiples and market share. Have that ready, or Claude will either skip those charts or ask for it. The four mandatory charts (revenue by product, revenue by geography, DCF sensitivity heatmap, valuation football field) are the ones readers look at first, so review them closely.

**Task 5 (Report Assembly).** Expect a long run. A 10,000+ word DOCX with embedded charts is the heaviest task, and it's the one most worth reading end to end before it goes anywhere.

## Practical Tips

- **One task per session is fine.** Each task writes its output to its own folder, and the next task reads those files. You don't need one marathon session, and starting fresh keeps each task focused.
- **The default font is Times New Roman.** Tell Claude at the start if your house style uses something else, so you don't have to reformat 40 pages later.
- **Treat it as a first draft, not publishable research.** If you work at a firm that publishes research, the report still goes through your normal supervisory and compliance review. For a buy-side memo or a stock-pitch competition, it's a strong starting structure.
- **Pick a company you can check.** For a first run, choose a company you already know well. Seeing where the output matches your own understanding (and where it doesn't) tells you how much to trust it on a new name.
