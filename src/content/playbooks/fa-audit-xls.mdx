## What This Does

Performs a systematic audit of spreadsheets and financial models across five phases: model inventory, formula-level checks, model integrity validation, logic and reasonableness testing, and cross-model consistency. Produces a severity-based audit report with specific cell references and fix recommendations.

## Audit Phases

1. **Model Inventory** — Catalog tabs, inputs, outputs, and data flow
2. **Formula-Level Checks** — Hard-coded overrides, inconsistent formulas, broken references, mixed units
3. **Model Integrity** — Balance sheet balancing, cash tie-outs, retained earnings rollforward, revenue builds
4. **Logic & Reasonableness** — Negative revenue, margin spikes, cash going negative, perpetuity growth vs WACC
5. **Cross-Model Consistency** — Revenue alignment across DCF/comps, share count consistency, discount rate consistency

## Severity Definitions

| Level | Definition | Action Required |
|-------|-----------|-----------------|
| **Critical** | Model produces incorrect output. Financial impact or broken linkage. | Must fix before any use. |
| **Warning** | Potential issue that may affect accuracy or indicates questionable assumptions. | Review and fix or document justification. |
| **Info** | Style, best practice, or minor observation. No direct impact on output. | Fix if time permits. |

## Tips & Best Practices

- **Trace precedents and dependents** for every key output cell using Excel's Ctrl+[ and Trace Dependents tools
- **Test extremes**: Set key inputs to 0, very large numbers, and negative numbers to see if the model handles edge cases
- **Spot-check against source data**: For historical periods, compare model values to actual filings (10-K, 10-Q)
- **Use a clean copy**: Audit on a separate copy so you can mark it up without altering the working version
- **Document everything**: Even items that pass should be noted as "checked and confirmed"
