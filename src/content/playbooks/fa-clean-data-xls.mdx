## What This Does

Provides a systematic workflow for cleaning messy spreadsheet data. Detects and fixes whitespace issues, inconsistent casing, numbers stored as text, date format problems, duplicates, blank cells, mixed-type columns, and encoding issues — all with user approval before applying changes.

## Cleaning Order

Fixes are applied in a specific order to avoid cascading issues:

1. **Encoding fixes** — Fix character encoding first since it affects all text operations
2. **Whitespace** — TRIM and CLEAN all text cells
3. **Casing standardization** — Title Case for names, UPPER for codes, etc.
4. **Number conversion** — Convert numbers-as-text to actual numbers
5. **Date standardization** — Convert all dates to ISO 8601 (YYYY-MM-DD)
6. **Category consolidation** — Merge inconsistent labels ("USA" / "US" / "United States")
7. **Duplicate removal** — Remove exact duplicates; flag near-duplicates for review
8. **Blank handling** — Fill, flag, or remove blanks based on context

## What Gets Detected

| Check | Example |
|-------|---------|
| Leading/trailing whitespace | "  John Smith  " |
| Numbers as text | Numeric values with text formatting |
| Date inconsistencies | "01/15/2024" vs "2024-01-15" vs "Jan 15, 2024" |
| Inconsistent categories | "USA", "US", "United States", "U.S." |
| Duplicates | Exact and near-duplicate rows |
| Special characters | Non-printable characters, BOM markers |
| Outliers | Values far outside expected range |

## Tips & Best Practices

- **Always back up** your original data before running any cleaning operations
- **Provide context**: Tell the assistant what each column represents so it can apply appropriate cleaning rules
- **Specify preferred formats**: Date format, casing preferences, category names
- **Flag columns to skip**: Some columns should not be cleaned (free-text notes, unique IDs with leading zeros)
- **Set a materiality threshold**: For large datasets, focus on issues affecting more than 1% of rows first
- **Iterate**: Run a first pass for critical issues, review, then run a second pass for refinements

## Handling Specific Data Types

The template includes specialized handling for phone numbers (strip non-numeric, standardize format), email addresses (lowercase, validate format, catch common typos like "gmial.com"), addresses (standardize abbreviations), and currency values (remove symbols, convert to numeric).
