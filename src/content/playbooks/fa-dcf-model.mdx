## What This Does

Creates institutional-quality DCF (Discounted Cash Flow) models for equity valuation following investment banking standards. Retrieves financial data, builds comprehensive cash flow projections with proper WACC calculations, performs sensitivity analysis, and outputs a professional Excel model with an executive summary.

## Model Components

The DCF model includes:
- **Unlevered Free Cash Flow projections** with detailed revenue, margin, and CapEx assumptions
- **WACC buildup** with cost of equity (CAPM), cost of debt, and capital structure weights
- **Terminal value** calculated via both perpetuity growth method and exit multiple method
- **Sensitivity analysis** tables varying WACC and terminal growth rate / exit multiple
- **Implied share price** with equity bridge (Enterprise Value to Equity Value)

## Key Constraints

- Every calculation is an Excel formula — never hardcoded computed values
- Terminal growth rate must not exceed WACC (the model validates this)
- All formulas use proper cell references so the model updates dynamically when assumptions change
- Sensitivity tables use odd dimensions (5x5 or 7x7) with the base case at the center cell

## Tips & Best Practices

- **Use formula-driven cells throughout** — the model must be dynamic and update when any input changes
- **Break circular references** by using beginning-of-period balances for interest calculations
- **Cross-check terminal value** — it typically represents 60-80% of total enterprise value; if it is outside this range, revisit assumptions
- **Run both terminal value methods** (perpetuity growth and exit multiple) and compare results for reasonableness
- **Sensitivity tables should show different values in every cell** — if values are identical, the formulas are not properly linked to the varying inputs

## Dependencies
