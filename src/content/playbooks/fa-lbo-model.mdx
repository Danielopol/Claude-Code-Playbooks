## What This Does

Builds investment banking-quality LBO (Leveraged Buyout) models in Excel by filling templates with correct formulas, proper formatting, and validated calculations. Covers Sources & Uses, operating model projections, multi-tranche debt schedules with cash sweep logic, returns analysis (IRR and MOIC), and sensitivity tables.

## Model Structure

The LBO model is built section by section with user verification at each checkpoint:

1. **Sources & Uses** — Transaction sizing, debt and equity split, fees
2. **Operating Model** — Revenue projections, margins, EBITDA buildup
3. **Debt Schedule** — Multi-tranche with mandatory amortization and cash sweep
4. **Returns Analysis** — IRR and MOIC calculations with proper cash flow signs
5. **Sensitivity Tables** — 5x5 or 7x7 grids varying entry multiple, exit multiple, and leverage

## Common Pitfalls to Avoid

- **Circular references in interest**: Use beginning-of-period balance for interest calculations, not ending balance
- **Negative debt balances**: Use MAX/MIN functions to prevent paying down more debt than exists
- **IRR sign errors**: Investment cash flows must be negative, proceeds must be positive
- **Sensitivity tables showing identical values**: Ensure formulas use mixed references ($A5 for row input, B$4 for column input)
- **Sources not equaling Uses**: One item must be the "plug" (balancing figure) calculated as the difference

## Tips & Best Practices

- **Work section by section** — complete one section, verify with the user, then proceed to the next
- **Sensitivity tables use odd dimensions** (5x5 or 7x7) so there is a true center cell representing the base case
- **The center cell of every sensitivity table must match the model's actual output** — this is the proof the table is wired correctly
- **Every calculation must be an Excel formula** — never compute values externally and hardcode results
- **Follow the template's sign convention consistently** throughout the entire model
