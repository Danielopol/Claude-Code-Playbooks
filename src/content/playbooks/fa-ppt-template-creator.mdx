## What This Does

Turns a user-provided PowerPoint template (.pptx or .potx) into a reusable skill that can generate on-brand presentations programmatically. Analyzes the template's layouts, placeholders, and content boundaries, then packages everything into a self-contained skill with complete documentation and code examples.

## What Gets Created

The generated skill includes:
- `assets/template.pptx` — the bundled template file
- `SKILL.md` — complete, self-contained instructions with layout documentation, placeholder mapping, content area boundaries, and working code examples

## Template Analysis

The tool extracts precise measurements from every layout in the template:
- **Placeholder positions** — exact x, y, width, height for titles, subtitles, footers, content areas
- **Content area boundaries** — the safe zone for custom shapes, tables, and charts (between subtitle and footer)
- **Layout inventory** — which layouts exist and what each is best used for (cover, content, two-column, etc.)

## Key Rules for Generated Skills

- **Template bundled in assets/** — the .pptx file travels with the skill
- **Self-contained SKILL.md** — all instructions embedded, no external references needed
- **No manual bullet characters** — use `paragraph.level` for hierarchy; the slide master handles formatting
- **Delete existing slides first** — always clear slides before adding new ones
- **Document placeholders by idx** — placeholder index values are template-specific and must be mapped precisely

## Tips & Best Practices

- **Finding the true content start**: The content area does not always start immediately after the subtitle placeholder — look for OBJECT placeholders (type 7) to determine where content should actually begin
- **Test with a sample presentation**: Always generate a sample deck to validate that the skill produces correctly formatted slides before distributing it
- **Content boundaries matter**: Custom content (textboxes, tables, charts) must stay within documented boundaries to avoid overlapping with template placeholders

## Dependencies

- Python (python-pptx) for template analysis and presentation generation
