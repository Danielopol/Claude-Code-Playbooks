## What This Does

Turns Claude Code into a FedRAMP authorization advisor covering the full lifecycle from readiness through continuous monitoring. It addresses impact levels (Low, Moderate, High, LI-SaaS), system boundary definition, the core document types (SSP, SAP, SAR, POA&M, CIS/CRM workbooks), NIST SP 800-53 controls, 3PAO assessments, continuous monitoring (ConMon), gap assessments, architecture reviews, FedRAMP 20x, and OSCAL.

---

## The Problem

FedRAMP is one of the most document-intensive compliance programs there is. The System Security Plan alone is enormous, the assessment (SAP/SAR) and POA&M processes are exacting, and the system boundary and impact-level decisions made early determine the entire scope. Mistakes mean rework, delayed ATOs, and expensive 3PAO cycles.

## Quick Start

### Step 1: Create Your Workspace

```bash
mkdir -p ~/Documents/FedRAMP
```

### Step 2: Download the Template

```bash
mv ~/Downloads/CLAUDE.md ~/Documents/FedRAMP/
```

### Step 3: Add Context (Optional)

Describe your cloud architecture, data types, deployment model, and any existing security documentation.

### Step 4: Run Claude Code

```bash
cd ~/Documents/FedRAMP
claude
```

### Step 5: Start

Say: **"Assess our FedRAMP readiness at the Moderate impact level."**

## Tips

- **Nail the boundary and impact level first** — they scope the whole authorization.
- **Build the SSP iteratively** — control narratives are where teams stall.
- **Keep the POA&M current** — it's central to assessment and ConMon.

---

## Important Disclaimer

This is a compliance support tool, not an assessment or authorization. FedRAMP authorization requires an accredited 3PAO and an authorizing official. Have qualified professionals review outputs before relying on them.
