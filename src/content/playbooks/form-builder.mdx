## What This Does

This workflow enables creation of intelligent document forms using **docassemble** - a platform for guided interviews that generate documents. Create questionnaires that adapt based on answers.

---

## Quick Start

### Step 1: Create a Project Folder

```bash
mkdir -p ~/Documents/FormBuilder
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Documents/FormBuilder/
```

### Step 3: Start Working

```bash
cd ~/Documents/FormBuilder
claude
```
