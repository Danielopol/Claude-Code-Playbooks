## What This Does

Helps plan and evaluate free tools as a marketing channel — for lead generation, organic traffic, and brand awareness — and assesses whether the idea is worth the build and maintenance.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/free-tool`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Describe your product, audience, and the tool idea (or ask Claude to brainstorm).

---

## Inputs You'll Need

- **Business context** — core product, audience, problems
- **Goals** — leads, SEO traffic, brand, product education
- **Resources** — engineering capacity, ongoing maintenance, promotion budget
- **Existing free tools in your space** — what already exists, what's missing

## How It Works

1. Brainstorm or evaluate tool ideas against demand (search volume, recurring need)
2. Score each idea on: lead value, SEO upside, build effort, maintenance load
3. Define the tool spec (inputs, outputs, magic moment, lead capture point)
4. Plan distribution (SEO content, communities, partnerships)
5. Define success metrics (uses, leads, links, ranking)
6. Build a promotion sequence

## What You Get

- Scored idea shortlist
- Tool specification (inputs, outputs, edge cases, lead-capture flow)
- SEO plan with target keywords and surrounding content
- Promotion launch plan
- Measurement framework
