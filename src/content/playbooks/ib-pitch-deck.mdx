## What This Does

This playbook populates investment banking pitch deck templates with financial data from source files (Excel, CSV, PDF). It follows a 5-phase workflow -- data extraction, content mapping, template population, validation, and final verification -- to ensure number consistency, proper formatting, and institutional presentation standards across every slide.

**Note**: This is for populating existing templates with data, not for creating presentations from scratch.

## Quick Start

### Step 1: Create a Project Folder

Create a folder for your deal workspace and place the downloaded template inside as `CLAUDE.md`.

```bash
mkdir -p ~/Documents/PitchDeck-ProjectNova
```

### Step 2: Download the Template

Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

```bash
mv ~/Downloads/ib-pitch-deck.md ~/Documents/PitchDeck-ProjectNova/CLAUDE.md
```

### Step 3: Add Your Files

Place these in the same folder:

## 5-Phase Workflow

| Phase | Purpose |
|-------|---------|
| 1. Data Extraction | Extract and validate data from source materials |
| 2. Content Mapping | Map source data to template placeholder sections |
| 3. Template Population | Fill slides with data, apply formatting |
| 4. Validation Loop | Convert to images, check, fix, repeat (up to 3 cycles) |
| 5. Final Verification | Run quality checklist before delivery |

---

## Critical Anti-Patterns to Avoid

- **Do not populate data INTO colored placeholder boxes** -- the placeholder tells you what content goes there; replace it with properly formatted content
- **Do not create text-based tables** using pipes or tabs -- always use actual PowerPoint table objects
- **Do not inherit placeholder contrast** -- production slides typically use dark text on light backgrounds

---

## Formatting Standards

| Element | Typical Size | Style |
|---------|-------------|-------|
| Slide title | 40-48pt | Bold |
| Section header | 14-16pt | Regular |
| Body text | 11-14pt | Regular |
| Table header | 10-12pt | Bold |
| Table body | 9-11pt | Regular |
| Footnotes | 8-9pt | Italic |

---

## Tips and Best Practices

- **Always back up the original template** before making any modifications
- **Cross-slide consistency** is critical -- the same metric must show the same number on every slide where it appears
- **Tables must be actual table objects**, never pipe-separated or tab-separated text
- **Validate visually** by converting slides to images after population
- The final file should be reviewed in Microsoft PowerPoint before distribution, as LibreOffice rendering may differ
- Include source citations in slide footnotes for all data points
