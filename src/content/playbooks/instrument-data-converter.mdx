## What This Does

Converts instrument files from cell counters, spectrophotometers, plate readers, qPCR systems, and more into standardized Allotrope Simple Model (ASM) format. Supports native parsing via allotropy library, flexible fallback parsing, and PDF extraction — with validation against ASM schemas.

## Output Formats

- **ASM JSON** — Full semantic structure with ontology URIs (for LIMS, data lakes)
- **Flattened CSV** — 2D tabular format (for Excel, quick analysis)
- **Python parser code** — Standalone script for data engineer handoff

---

## Parsing Strategy

1. **Native allotropy** (preferred) — Try allotropy library first for supported vendors
2. **Flexible fallback** — Column name fuzzy matching, unit extraction from headers
3. **PDF extraction** — Extract tables using pdfplumber, then apply fallback parsing

---

## Tips

- Always validate ASM output before delivering — run the validation script
- Separate raw measurements from calculated/derived values
- When unsure about field mapping, ask for clarification rather than guessing
- Check `references/supported_instruments.md` for the complete instrument list
