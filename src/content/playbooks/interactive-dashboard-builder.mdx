## What This Does

Builds self-contained interactive HTML dashboards with charts, filters, tables, and professional styling. The generated dashboard opens directly in a browser with no server or dependencies required -- just share the HTML file with anyone.

---

## Dashboard Layout

Every dashboard follows a standard layout pattern:

- **KPI cards** at the top for headline numbers (2-4 cards)
- **Charts** in the middle section for trends and breakdowns (1-3 charts)
- **Detail table** at the bottom for drill-down data (sortable, scrollable)
- **Filters** in the header or sidebar depending on complexity

---

## Supported Chart Types

- **Line chart**: Time series trends
- **Bar chart**: Category comparisons
- **Doughnut chart**: Composition (when fewer than 6 categories)
- **Stacked bar**: Composition over time
- **Mixed (bar + line)**: Volume with rate overlay

---

## Data Size Guidelines

| Data Size | Approach |
|---|---|
| Less than 1,000 rows | Embed directly in HTML with full interactivity |
| 1,000 - 10,000 rows | Embed in HTML, may need to pre-aggregate for charts |
| 10,000 - 100,000 rows | Pre-aggregate server-side, embed only aggregated data |
| More than 100,000 rows | Not suitable for client-side dashboard |

---

## Tips

- Dashboards are fully self-contained HTML files -- share them with anyone by sending the file
- For real-time dashboards, consider connecting to a BI tool instead; these dashboards are point-in-time snapshots
- Request "dark mode" or "presentation mode" for different styling
- You can request a specific color scheme to match your brand
