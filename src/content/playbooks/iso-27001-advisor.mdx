## What This Does

Turns Claude Code into an ISO/IEC 27001 compliance assistant. It runs gap analysis and audits, writes security policies, generates the Statement of Applicability (SoA), builds risk assessments, risk registers, and risk treatment plans, applies Annex A controls (2013 and 2022), guides ISMS implementation and clause requirements, supports the 2013-to-2022 transition, and produces certification-readiness checklists.

---

## The Problem

ISO 27001 is the de-facto security credential for selling to larger customers, but the management-system requirements (Clauses 4-10) plus Annex A controls, the SoA, and a defensible risk process are a lot to assemble. Teams either over-engineer it or discover gaps weeks before an audit. The 2013-to-2022 control restructuring adds another layer for organizations already certified.

## Quick Start

### Step 1: Create Your Workspace

```bash
mkdir -p ~/Documents/ISO-27001
```

### Step 2: Download the Template

```bash
mv ~/Downloads/CLAUDE.md ~/Documents/ISO-27001/
```

### Step 3: Add Context (Optional)

Add existing policies, your asset inventory, and a description of your systems and data flows.

### Step 4: Run Claude Code

```bash
cd ~/Documents/ISO-27001
claude
```

### Step 5: Start

Say: **"Run an ISO 27001 gap analysis and tell me how far we are from certification."**

## Tips

- **Anchor the SoA in real risks** — auditors check the link between risk and controls.
- **Write policies you'll actually follow** — evidence of operation matters more than length.
- **Plan the 2022 transition** if you're already certified to 2013.

---

## Important Disclaimer

This is a compliance support tool, not a certification audit. Certification requires an accredited body. Have qualified security and audit professionals review outputs before relying on them.
