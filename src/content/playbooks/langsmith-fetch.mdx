## What This Does

Debug LangChain and LangGraph agents by fetching execution traces from LangSmith Studio. Investigate agent behavior, errors, tool calls, memory operations, and performance metrics through terminal commands.

---

## Quick Start

### Step 1: Install

```bash
pip install langsmith-fetch
```

### Step 2: Configure

```bash
export LANGSMITH_API_KEY="your_key"
export LANGSMITH_PROJECT="your_project"
```

### Step 3: Debug

```bash
claude
```

Then say: **"Debug my agent's recent activity"**

---

## Four Debug Workflows

| Workflow | Purpose |
|----------|---------|
| Quick Debug | Last 5 minutes of activity |
| Deep Dive | Analyze specific trace ID |
| Export Session | Save traces for sharing |
| Error Detection | Find and categorize errors |
