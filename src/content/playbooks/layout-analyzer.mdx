## What This Does

This workflow enables document layout analysis using **surya** - an advanced document understanding system. Detect text blocks, tables, figures, headings, and determine reading order in complex documents.

---

## Quick Start

### Step 1: Create a Project Folder

```bash
mkdir -p ~/Documents/LayoutAnalyzer
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Documents/LayoutAnalyzer/
```

### Step 3: Start Working

```bash
cd ~/Documents/LayoutAnalyzer
claude
```
