## What This Does

Helps you produce professional marketing images using AI generation models (Flux, Midjourney, DALL-E, Ideogram, Gemini), design tools (Canva, Figma), and optimization best practices — for blog heroes, social graphics, product mockups, profile banners, listing visuals, brand assets, and OG images.

### Step 3: Run the Workflow

Describe the image you need, the placement, and any brand assets.

## Inputs You'll Need

- **Image goal** — blog hero, social graphic, product mockup, banner, brand asset, OG image
- **Platform / placement** — website, social, directory listing, app store, email
- **Dimensions** — required size or aspect ratio
- **Brand assets** — logo, colors, fonts, style guide
- **Model preference** — if any (Flux, Midjourney, DALL-E, Ideogram, Gemini)

## How It Works

1. Match the image type to the right model and tool
2. Construct a prompt with brand context, subject, style, composition, and constraints
3. Iterate on variations and select the best
4. Composite/edit in Canva or Figma where helpful (text overlays, logos)
5. Optimize for the placement (WebP, responsive sizes, alt text, OG)
6. Save reusable prompts and styles for future consistency

## What You Get

- Final image (or set) at the required dimensions
- Prompt + parameters used (for reproducibility)
- Optimized files (WebP, JPG, PNG as appropriate)
- OG / social variants
- Reusable style notes for brand consistency
