## What This Does

Build high-quality MCP (Model Context Protocol) servers that enable LLMs to interact with external services and APIs. Follow best practices for Python (FastMCP) or Node/TypeScript implementations.

## Quick Start

### Step 1: Create an MCP Project

```bash
mkdir -p ~/Projects/my-mcp-server
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Projects/my-mcp-server/
```

### Step 3: Start Building

```bash
cd ~/Projects/my-mcp-server

```

Then say: **"Help me build an MCP server for [service/API]"**

## Key Design Principles

### Build for Workflows
- Don't just wrap API endpoints
- Create tools that enable complete tasks
- Consolidate related operations

### Optimize for Context
- LLMs have limited context windows
- Return high-signal information only
- Provide concise vs detailed options

### Actionable Errors
- Guide agents toward correct usage
- Suggest specific next steps
- Make errors educational

## Tool Annotations

```python
@mcp.tool(
    readOnlyHint=True,      # Read-only operations
    destructiveHint=False,   # Non-destructive
    idempotentHint=True,     # Same result on repeat
    openWorldHint=True       # External systems
)
```

## Quality Checklist

## Tips

- **Research thoroughly**: Study all API documentation first
- **Design for agents**: Think about what workflows LLMs need
- **Test with evaluation**: Create realistic test scenarios
- **Iterate based on feedback**: Let agent performance guide improvements
