## What This Does

This workflow enables conversion from Markdown to various Office formats using **Pandoc** - the universal document converter. Convert your Markdown files to professional Word documents, PowerPoint presentations, PDFs, and more while preserving formatting and structure.

---

## Quick Start

### Step 1: Create a Project Folder

```bash
mkdir -p ~/Documents/MdToOffice
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Documents/MdToOffice/
```

### Step 3: Start Working

```bash
cd ~/Documents/MdToOffice
claude
```
