## What This Does

Applies Barbara Minto's Pyramid Principle to any draft or raw idea. It extracts a three-level pyramid (one-sentence answer, 2–4 MECE supporting arguments, one piece of concrete evidence per argument), runs a structural diagnosis, and delivers the results as a visual HTML artifact saved to your working directory.

The HTML file shows the full pyramid as a color-coded hierarchy, provides an exact replacement opener, and lists a numbered restructuring plan with specific paragraph-level actions. Evidence nodes are color-coded: blue for strong (concrete, named, specific) and red for weak or missing. Chat gets a link and a 2–4 line summary — the HTML holds everything else.

This runs in two modes depending on what you feed it:

- **Existing draft** — extracts the pyramid from what you wrote, maps each argument to specific paragraphs, identifies dead-weight sections, and tells you what to cut, move, or rewrite.
- **Raw idea** — builds the pyramid from scratch and delivers a recommended skeleton to draft from, with the opener and evidence targets you need to find.

## Quick Start

### Step 1: Create a project folder

```bash
mkdir ~/minto-drafts
cd ~/minto-drafts
```

Or navigate to any folder where you keep drafts and documents.

### Step 2: Download and place the template

Click **Download** above and save the file to that folder as `CLAUDE.md`.

### Step 3: Launch Claude Code

```bash
claude
```

### Step 4: Trigger the skill on a draft or idea

Paste your draft into the conversation, then use one of the trigger phrases:

```
minto this
run minto
apply minto
pyramid this
build the pyramid
answer-first this
structure this as a pyramid
```

Or paste a raw idea and say "minto this" — no existing draft required.

The skill saves an HTML file to your working directory and responds with a link plus a short summary of the biggest structural issue found.

## What the HTML Artifact Contains

The output file (`minto-pyramid-{topic}.html`) has three sections:

**The Pyramid** — a visual hierarchy with three tiers:
- Top: the one-sentence answer (black box)
- Middle: 2–4 argument nodes (amber/yellow)
- Bottom: one evidence node per argument, color-coded blue (strong) or red (weak/missing)

**Your Opener** — the exact sentence the draft should lead with, plus a note explaining why it beats the current opener. Principle pieces get an answer-first opener; case study pieces lead with the concrete.

**Restructuring Plan** — numbered, paragraph-level actions: move the claim, merge the overlapping sections, cut the dead weight, find the missing evidence, sharpen the weak argument. Each step is specific enough to execute without reinterpretation.

## Tips & Best Practices

- **Run Minto before any other writing or editing skill.** Voice, format, and platform choices are downstream concerns. Get the structure sound first, then style.
- **Feed it the full draft, not a summary.** The skill maps arguments to specific paragraphs in your draft. A summary loses the location data the restructuring plan depends on.
- **If "minto this" returns a question, answer it.** When the target is ambiguous (two drafts in the conversation, a vague topic), the skill asks one clarifying question before proceeding. Resolve it and it continues.
- **Paste evidence into the conversation if you have it.** The skill uses evidence you provide before flagging gaps. If you have the stat or the named example already, include it when you trigger the skill.
- **Use it on slide decks and presentations too.** Paste the slide titles and bullet points as text. The pyramid logic applies to any structured argument, not just prose.
- **Three arguments is the sweet spot.** If your idea seems to need five, the answer is probably too broad. The skill will push back on Level 1 before generating more than four arguments.

## Limitations

- **No full rewriting.** The skill delivers a restructuring plan, not a rewritten draft. Executing the plan is your job (or a downstream writing skill's job).
- **Evidence fabrication is never done.** If an argument lacks concrete evidence and none was provided in the conversation, the skill flags the gap and tells you what type of evidence to find. It does not invent sources, stats, or quotes.
- **No format or platform recommendations.** The skill diagnoses structure and logic. It will not suggest whether the content should be a memo, a thread, a slide deck, or a blog post.
- **HTML is saved to the working directory.** In Claude Code, the artifact lands in the directory where you launched `claude`. Open it in a browser to see the full visual output.
- **Raw ideas without a clear claim may stall.** If the idea cannot be compressed to a one-sentence contestable claim, the skill stops and tells you what is blocking the compression. Resolve that first.
- **No voice or style work.** Structure and logic only. Voice, tone, and phrasing are explicitly out of scope for this skill.
