## What This Does

Turns Claude Code into a NIST Cybersecurity Framework advisor covering CSF 2.0 and CSF 1.1. It assesses posture across the six functions (Govern, Identify, Protect, Detect, Respond, Recover), builds organizational and community profiles, rates implementation tiers, runs gap assessments against the CSF core subcategories, explains what CSF 2.0 changes, and maps to NIST SP 800-53, ISO 27001, CIS Controls, and COBIT.

---

## The Problem

The CSF is powerful precisely because it's flexible — which also makes it hard to operationalize. Teams know the six functions but struggle to turn them into a current profile, a defensible target profile, and a prioritized roadmap that leadership can fund. CSF 2.0's new Govern function and updated subcategories add work for organizations already mapped to 1.1.

## Quick Start

### Step 1: Create Your Workspace

```bash
mkdir -p ~/Documents/NIST-CSF
```

### Step 2: Download the Template

```bash
mv ~/Downloads/CLAUDE.md ~/Documents/NIST-CSF/
```

### Step 3: Add Context (Optional)

Describe your environment, current controls, risk appetite, and any existing framework work.

### Step 4: Run Claude Code

```bash
cd ~/Documents/NIST-CSF
claude
```

### Step 5: Start

Say: **"Assess our cybersecurity posture against NIST CSF 2.0 and build a target profile."**

## Tips

- **Use profiles to communicate** — current vs. target is how you brief leadership.
- **Take Govern seriously** — CSF 2.0 elevates governance for a reason.
- **Map to your other frameworks** — avoid duplicating control work.

## Important Disclaimer

This is a cybersecurity planning and assessment tool, not a certification. Have qualified security professionals review profiles and assessments before relying on them.
