## What This Does

Optimizes user onboarding and activation so new users reach their "aha moment" quickly and establish habits that lead to long-term retention — covering checklists, tours, empty states, first-run experiences, and re-engagement.

## Inputs You'll Need

- **Product context** — B2B/B2C, core value, complexity
- **Activation definition** — the action that signals "they get it"
- **Current state** — what happens after signup, where drop-offs occur
- **Data** — funnel metrics, session recordings if available

## How It Works

1. Define (or refine) the activation event — the specific action correlated with retention
2. Map the current path from signup to activation
3. Identify drop-off points and their root cause (friction, confusion, no value yet)
4. Apply the right onboarding pattern (checklist, tour, empty state, magic moment)
5. Cut steps that don't move toward activation; sharpen the ones that do
6. Design re-engagement triggers for users who stall
7. Define metrics — activation rate, time-to-activation, day-7 retention

## What You Get

- Aha-moment / activation event definition
- Current funnel breakdown with drop-off diagnosis
- Recommended onboarding pattern with step-by-step flow
- Cut/keep decisions per existing step
- Re-engagement sequence (in-app + email)
- Metrics dashboard with leading and lagging indicators
