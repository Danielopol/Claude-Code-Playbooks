## What This Does

Create professional pitch decks for investors, sales presentations, or product launches. Claude guides you through information gathering and generates a structured 10-slide presentation following industry best practices.

---

## Quick Start

### Step 1: Create a Pitch Folder

```bash
mkdir -p ~/Documents/PitchDeck
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Documents/PitchDeck/
```

### Step 3: Start Creating

```bash
cd ~/Documents/PitchDeck
claude
```

Then say: **"Help me create an investor pitch deck"**

## Standard 10-Slide Structure

| Slide | Content |
|-------|---------|
| 1. Title | Company name, tagline, your name |
| 2. Problem | Pain point you're solving |
| 3. Solution | Your product/service |
| 4. Market | TAM/SAM/SOM opportunity |
| 5. Product | Key features and demo |
| 6. Traction | Metrics and milestones |
| 7. Business Model | How you make money |
| 8. Competition | Competitive landscape |
| 9. Team | Key people and experience |
| 10. Ask | Funding ask and use of funds |

---

## Information Gathered

### Required
- Company basics (name, stage, industry)
- Problem statement
- Solution description
- Business model

### Optional (Strengthens Deck)
- Market size data
- Product details/screenshots
- Traction metrics
- Competition analysis
- Team backgrounds
- Financial projections

## Design Standards

| Element | Guideline |
|---------|-----------|
| Title Font | 54pt |
| Body Text | 18-20pt |
| Primary Color | Blue (#2962FF) |
| Background | Clean white |
| Bullets Per Slide | 3-5 maximum |
| Key Message | One per slide |

---

## Tips

- **Know your audience**: Investor decks differ from sales decks
- **Lead with the problem**: Make them feel the pain
- **Show traction early**: Numbers build credibility
- **Keep it visual**: Less text, more impact
- **Practice the story**: The deck supports your narrative
