## What This Does

Orchestrates 8 phases of PRD creation — exec summary, problem statement, personas, strategic context, solution overview, success metrics, user stories, out of scope — over 2-4 days. Calls component skills (`problem-statement`, `proto-persona`, `epic-hypothesis`, `user-story`) at each phase.

Anti-pattern: PRD as waterfall spec. This is a living document for alignment, not a frozen contract.

## Quick Start


Provide discovery insights, persona research, business goals, and competitive context. Claude orchestrates the 8-phase workflow and outputs a complete PRD.

## The 8 Phases

| Phase | Time | Output |
|-------|------|--------|
| **1. Executive Summary** | 30 min | One paragraph (problem + solution + impact) |
| **2. Problem Statement** | 60 min | Who/what/why/evidence |
| **3. Target Users** | 30 min | Primary + secondary personas |
| **4. Strategic Context** | 45 min | OKRs, market, competition, why now |
| **5. Solution Overview** | 60 min | High-level description (not pixel spec) |
| **6. Success Metrics** | 30 min | Primary + secondary + guardrails |
| **7. User Stories** | 90-120 min | Epic hypothesis + stories with acceptance criteria |
| **8. Scope & Dependencies** | 30 min | Out of scope, dependencies, risks, open questions |

---

## Tips & Best Practices

- **Write the exec summary first, refine it last.** Forces clarity upfront, captures lessons at the end.
- **Evidence in the problem statement.** Customer quotes + analytics + support tickets — not "we believe."
- **Solution overview is high-level.** Don't spec UI in the PRD. Let design own pixels.
- **Always define a primary metric.** Without it, you can't know if the feature succeeded.
- **Document out of scope explicitly.** Prevents scope creep and stakeholder surprise.

---

## Common Pitfalls

- PRD written in isolation, presented as finished doc (no buy-in)
- "We believe users have this problem" with no data
- Pixel-level UI spec that removes design collaboration
- No success metrics defined upfront
- No "out of scope" section, leading to scope creep
