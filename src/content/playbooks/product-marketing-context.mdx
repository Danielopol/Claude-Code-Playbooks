## What This Does

Creates and maintains a product marketing context document at `.agents/product-marketing-context.md` that captures foundational positioning and messaging information — so every other marketing skill (copywriting, ad-creative, content-strategy, etc.) reads it automatically and skips the foundational questions.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/<project>`). This context file lives at the root of any marketing project.

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Describe your product — Claude will guide creation of the context document and save it to `.agents/product-marketing-context.md`.

---

## Inputs You'll Need

- **Product** — what it does, who it's for, what problems it solves
- **Audience** — ICP, segments, decision-makers
- **Positioning** — category, differentiators, value proposition
- **Voice and tone** — brand personality
- **Competitors** — direct, indirect, alternatives
- **Existing assets** — website, decks, docs (optional, used to extract context)

## How It Works

1. Check if the context already exists (and offer to update or migrate older `.claude/` versions)
2. If new, offer two paths — guided questions or extraction from existing assets
3. Capture product, audience, positioning, voice, and competitive context
4. Save to `.agents/product-marketing-context.md`
5. Validate that the file is read by other marketing skills

## What You Get

- A complete `.agents/product-marketing-context.md` file
- Reusable foundation for every downstream marketing skill
- Easy update flow when positioning evolves
