## What This Does

Creates structured IP documentation — invention disclosures, patent portfolio tracking, trade secret registries, and IP strategy documents — that protect organizational innovations and support IP-related business decisions.

| Type | Purpose |
|------|---------|
| **Invention Disclosure** | Formal documentation of new inventions |
| **Patent Portfolio Tracker** | Status and strategy for patent applications |
| **Trade Secret Registry** | Inventory of protected trade secrets |
| **IP Landscape Analysis** | Competitive IP positioning |
| **License Management** | Inbound and outbound license tracking |
| **IP Strategy Document** | Filing priorities and protection approach |

---

## Tips
- **Document early**: Capture inventions when they happen — details fade and prior art accumulates
- **Prior art matters**: A thorough search saves money on doomed applications
- **Business value first**: Prioritize IP protection by commercial importance, not novelty
- **Trade secrets need process**: They're only protected if you can prove you protected them

## Troubleshooting

**Too many inventions to document**
Say: "Triage by commercial value and competitive advantage. Document high-value innovations first."

**Unclear if something is patentable**
Ask: "Document the innovation regardless. Let patent counsel determine patentability."

**Trade secret protections weak**
Specify: "Audit access controls, NDAs, and documentation for each registered trade secret."
