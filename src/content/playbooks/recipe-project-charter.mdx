## What This Does

Generates complete project charter packages — scope definition, objectives, stakeholder analysis, risk register, timeline, and kickoff meeting materials — that align teams and set projects up for success from day one.

---

## Quick Start

### Step 1: Download the Template
Click **Download** above to get the `CLAUDE.md` file.

### Step 2: Define the Project
Describe the project goal, business justification, key stakeholders, and known constraints (budget, timeline, resources).

### Step 3: Start Using It
```bash
claude
```
Say: **"Create a project charter for our CRM migration from Salesforce to HubSpot. 6-month timeline, $200K budget, 50 users to migrate."**

---

## Charter Components

| Component | Content |
|-----------|---------|
| **Business Case** | Why this project, what problem it solves |
| **Scope Statement** | In-scope, out-of-scope, assumptions |
| **Objectives & KPIs** | Measurable success criteria |
| **Stakeholder Register** | Who, their role, influence, and communication needs |
| **Risk Register** | Identified risks with probability and mitigation |
| **Timeline** | Major milestones and phase gates |
| **Kickoff Deck** | Presentation for the project kickoff meeting |

---

## Tips
- **Explicit out-of-scope**: What you won't do is as important as what you will
- **SMART objectives**: Specific, Measurable, Achievable, Relevant, Time-bound
- **Risk thinking early**: Identifying risks at charter stage is cheap; discovering them mid-project is expensive
- **Stakeholder communication plan**: Define frequency and format before the project starts

## Troubleshooting

**Scope keeps growing**
Say: "Lock the scope statement and create a change request process for additions."

**Too many stakeholders**
Ask: "Use RACI to clarify who's Responsible, Accountable, Consulted, and Informed."

**Unclear success criteria**
Specify: "Define 3 measurable KPIs that prove this project succeeded."
