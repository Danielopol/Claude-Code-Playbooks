## What This Does

Creates consistent project health reports with RAG (Red/Amber/Green) status indicators, milestone tracking, risk updates, budget status, and stakeholder-ready executive summaries. Standardizes reporting across all projects.

---

## Quick Start

### Step 1: Download the Template
Click **Download** above to get the `CLAUDE.md` file.

### Step 2: Gather Project Data
Compile current milestone status, budget actuals, risk register updates, and team updates.

### Step 3: Start Using It
```bash
claude
```
Say: **"Generate a weekly project status report. Overall: Amber. We hit the design milestone but the API integration is 1 week behind."**

## Report Structure

| Section | Content |
|---------|---------|
| **Overall Status** | RAG indicator with one-line summary |
| **Milestone Tracker** | Status of each milestone with dates |
| **Accomplishments** | What was completed this period |
| **Upcoming** | What's planned for next period |
| **Risks & Issues** | Updated risk register with new items |
| **Budget Status** | Planned vs. actual spend |
| **Decisions Needed** | What stakeholders need to approve |

---

## Tips
- **Honest RAG status**: Amber early is helpful; Red late is devastating
- **Decisions needed section**: Don't bury requests — put them front and center
- **Trend matters**: Is the project getting better or worse? Include directional arrows
- **Consistent format**: Same structure every week so stakeholders know where to look

## Troubleshooting

**Reports take too long to create**
Say: "Use bullet points only. No narratives — stakeholders scan, they don't read."

**Everything is always Green**
Ask: "Define specific criteria for Green/Amber/Red. Remove subjective assessment."

**Stakeholders don't read reports**
Specify: "Put the decision needed and biggest risk in the first 2 lines."
