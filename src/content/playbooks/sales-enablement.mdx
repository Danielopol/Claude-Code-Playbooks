## What This Does

Creates B2B sales collateral that reps actually use — pitch decks, one-pagers, objection handling docs, demo scripts, talk tracks, ROI tools, and playbooks — built around the deal moments where reps need help most.

---

## Quick Start

### Step 1: Create a Project Folder

Create a dedicated folder for this workflow (e.g. `~/marketing/sales-enablement`).

### Step 2: Download the Template

Click **Download** above and save the file as `CLAUDE.md` in that folder.

### Step 3: Run the Workflow

Describe your product, sales motion, ICP, and where reps currently struggle.

---

## Inputs You'll Need

- **Value prop and differentiators**
- **Sales motion** — self-serve, inside, field, hybrid
- **ICP and buyer personas**
- **Common objections** and competitive pressure
- **Current collateral** — what exists, what's missing, what reps actually use

## How It Works

1. Map the deal lifecycle (first touch → discovery → demo → procurement → close)
2. Identify the moments where reps need collateral
3. Build the right artifact for each moment (deck, one-pager, demo script, ROI tool)
4. Write objection responses with proof and talk tracks
5. Build buyer-persona variations where needed
6. Package into a usable library reps can navigate

## What You Get

- Pitch deck and one-pager
- Objection handling doc with talk tracks
- Demo script with anchor moments
- ROI tool or framework
- Persona-specific pitch variants
- Sales playbook tying it all together

## Tips & Best Practices

- **One page max** for battle cards and one-pagers — reps won't scroll
- **Lead with outcomes, not features**
- **Talk tracks beat bullet points** — give reps something they can paste or say
- **Update quarterly** — competitive landscape and product change fast
