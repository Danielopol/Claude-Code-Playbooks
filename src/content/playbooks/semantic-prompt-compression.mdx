## What This Does

A precise discipline for compressing load-bearing, machine-executed text — system prompts, tool and function descriptions, skill bodies, agent instructions — where a model executes the text cold with no author present to disambiguate a mistake. The core reframe: compression is re-encoding, not word deletion. Stripping function words out of an English sentence leaves a damaged English sentence; the actual technique re-frames each claim into a construction (a verbless assertion, a label frame, a condition→consequence arrow) whose grammar is punctuation and layout, so the function words have no work left to do and drop out on their own.

It opens with a density gate that stops the whole exercise before it starts if the text is already dense enough that compression would lose more than it saves, requires a full payload inventory (every MUST/NEVER line, identifier, and default) before anything gets deleted, and closes with a verification pass that names every declared loss explicitly and measures the real token delta against the target model's actual tokenizer — since word counts and symbol substitutions don't reliably predict token savings, and a naive pass has been measured silently dropping a real behavioral rule while claiming a saving.

## Tips & Best Practices

- Run the density gate honestly — the biggest failure mode isn't under-compressing, it's compressing an already-dense house-style prompt and silently losing a throw condition or a NEVER rule in the process.
- When in doubt about a connective symbol, write the word instead. The whole point of this register is a model executing it cold with no author to disambiguate — an ambiguous glyph is worse than a slightly longer sentence.
- Never compress a tool or skill's trigger description the way you compress its body — the description is retrieval surface matched against varied user phrasing, and keeping natural, redundant alternatives there is load-bearing, not wasteful.

## Limitations

- Built for load-bearing, machine-executed text — applying this register to human-facing narrative prose, teaching documentation, or marketing copy actively works against those genres' actual goals.
- Token-cost claims about specific symbols are tokenizer-dependent — always measure the real delta with the target model's actual tokenizer rather than assuming a glyph substitution saves tokens.
- A text-level compression discipline, distinct from information-architecture decisions like what belongs in-file versus behind a pointer — pair it with a document-structure playbook for that separate concern.
