## What This Does

Plans website structure — page hierarchy, navigation, URL patterns, breadcrumbs, and internal linking — so the site is intuitive for users and optimized for search engines.

## Inputs You'll Need

- **Business context** — what the company does, audiences, top 3 site goals
- **Current state** — new site or restructure; existing IA
- **Page inventory** — current pages and rough categories
- **SEO targets** — keyword clusters, top-performing pages

## How It Works

1. Identify primary audiences and top user paths
2. Group content into logical hubs and clusters
3. Define URL patterns that scale and stay readable
4. Plan main and secondary navigation
5. Design internal linking strategy (hub-and-spoke, breadcrumbs, contextual)
6. Map redirects if restructuring an existing site
7. Produce a visual sitemap

## What You Get

- Visual sitemap (markdown or diagram)
- URL pattern guide
- Navigation design (primary, secondary, footer)
- Internal linking strategy with examples
- Redirect map (if applicable)
- Implementation notes for the dev team
