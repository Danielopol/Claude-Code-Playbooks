## What This Does

Create new Claude skills with standardized structure and metadata, then automatically distribute them to team Slack channels. Streamlines the skill development pipeline from creation to team notification.

---

## Quick Start

### Step 1: Set Up Workspace

```bash
mkdir -p ~/Projects/team-skills
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Projects/team-skills/
```

### Step 3: Create and Share

```bash
cd ~/Projects/team-skills
claude
```

Then say: **"Create a skill for [use case] and share it with the team"**

## Five-Stage Pipeline

| Stage | Action |
|-------|--------|
| 1. Initialize | Provide skill details |
| 2. Create | Build directory structure |
| 3. Validate | Check metadata completeness |
| 4. Package | Prepare for distribution |
| 5. Notify | Post to Slack channel |

---

## What Gets Created

```
my-skill/
├── SKILL.md          # Core skill definition
├── scripts/          # Executable code
├── references/       # Documentation
└── assets/           # Templates and outputs
```

---

## Quality Assurance

Before distribution, the tool validates:
- SKILL.md format compliance
- Required metadata fields
- Hyphenated naming convention
- Directory structure

---

## Slack Notification

When shared, the team receives:
- Skill name and description
- Metadata summary
- Direct file links
- Usage instructions

## Tips

- **Use hyphenated names**: `my-skill-name` not `mySkillName`
- **Complete metadata**: All fields required for distribution
- **Test before sharing**: Validate locally first
- **Configure Slack channel**: Set destination before sharing
