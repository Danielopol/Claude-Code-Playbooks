## What This Does

Create animated GIFs optimized for Slack's specific technical requirements. Build message GIFs or custom emoji with composable animation primitives while staying within file size limits.

## Quick Start

### Step 1: Install Dependencies

```bash
pip install Pillow imageio numpy
```

### Step 2: Create a GIF Project

```bash
mkdir -p ~/Projects/slack-gifs
```

### Step 3: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Projects/slack-gifs/
```

### Step 4: Start Creating

```bash
cd ~/Projects/slack-gifs
claude
```

Then say: **"Create a celebration GIF for Slack"**

## Two GIF Types

| Type | Max Size | Dimensions | FPS | Duration |
|------|----------|------------|-----|----------|
| Message | ~2MB | 480x480 | 15-20 | 2-5 sec |
| Emoji | 64KB | 128x128 | 10-12 | 1-2 sec |

## Optimization Tips

If your GIF is too large:

1. Reduce frame count
2. Shrink color palette
3. Decrease dimensions
4. Simplify the design

Emoji GIFs (64KB limit) need aggressive optimization.

---

## Validation

The toolkit automatically warns when:
- File exceeds size limits
- Dimensions are wrong
- Frame rate is too high
- Colors exceed palette limit

## Philosophy

This toolkit provides **building blocks, not rigid recipes**:
- Understand your vision
- Design in phases
- Apply primitives flexibly
- Validate constraints
- Iterate as needed

## Tips

- **Start simple**: Basic animations first

- **Emoji is hard**: 64KB requires creativity
