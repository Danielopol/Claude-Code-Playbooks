## What This Does

Turns Claude into a personal tutor that uses the Socratic (maieutic) method. Instead of lecturing, it asks questions that make you predict, explain, and defend your reasoning. Each topic is split into 4-10 subskills, and each subskill is scored on a strict 0-5 scale that you earn through demonstrated performance, not by agreeing with an explanation.

It only starts when you ask to be taught: "teach me", "tutor me", "quiz me", "drill me", or "help me master". A one-off "what is X?" gets a normal answer. If it's unclear which you want, Claude asks one short question first.

## How a Session Runs

1. **Diagnostic.** Claude splits the topic into subskills and asks 3-5 questions, one at a time, from easy to hard. It teaches nothing until this is done.
2. **Skill map.** You see a progress bar per subskill (levels 0-5) and a proposed starting point. You can override it.
3. **Teaching loop.** For each subskill Claude asks one question and stops. If you're wrong, it asks a narrower question that exposes the contradiction rather than giving the answer. It explains directly only after 2-3 failed attempts, then re-tests the same idea from a different angle.
4. **Devil's advocate.** When you're right, Claude sometimes pushes back ("are you sure? what about X?") to check you can defend the answer.
5. **Spaced review.** Earlier subskills are re-tested without warning. Fail one and its level drops.
6. **Final assessment.** The course ends only when every subskill hits the target (4/5 by default, 5/5 if you ask for full mastery). A mixed assessment with at least one question per subskill and one integrative problem decides it.

## The Skill Map

```
0 unaware . 1 heard of it . 2 can follow along . 3 can do with help
4 can do independently . 5 can teach it / handle edge cases
```

Claude redraws the map after every level change, and whenever you ask for progress. Levels are strict: a level goes up only after 2+ independent checks, at least one of them unprompted recall. Level 5 also needs you to handle an edge case and explain the concept well enough that Claude would trust you to teach it.

## Commands You Can Use Anytime

| Say this | What happens |
| --- | --- |
| "show progress" | Renders the skill map |
| "harder" / "easier" | Adjusts question difficulty |
| "just tell me" | Skips Socratic mode for the current question only |
| "save state" | Outputs a compact block (topic, levels, misconceptions, what's covered) you can paste into a new session |
| "resume from:" + a saved block | Restores the map and continues where you left off |

## Tips & Best Practices

- **Answer in your own words.** Claude is told not to credit insight you didn't express, so vague answers get probed, not accepted.
- **Expect no flattery.** Feedback like "Not quite. Why would X happen if Y were true?" is the design, not rudeness.
- **Use real exercises for technical topics.** Where tools are available, Claude can ask you to write a query or predict what code prints, then check your actual output rather than your description of it.
- **Pick a narrow topic, or accept a branch.** For broad subjects Claude builds a two-level tree and works one branch at a time.
- **Save state before you stop.** Long courses span sessions. Paste the saved block into a new session to pick up where you left off.

---

## Limitations

- It's a drill, not a reference. If you only want an answer, ask a plain question or say "just tell me".
- A mastery session takes real time. A broad topic can run for many sessions, which is why save and resume exist.
- The skill levels are Claude's judgment from your answers. They're a useful guide, not a certification.
