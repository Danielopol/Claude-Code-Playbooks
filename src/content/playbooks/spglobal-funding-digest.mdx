## What This Does

Compiles recent funding rounds and capital markets activity into a polished one-page PowerPoint slide. The skill resolves entity identifiers, pulls funding data from S&P Capital IQ, validates results across multiple fallback strategies, and formats everything into a professional PPTX with key takeaways, valuation data, and direct Capital IQ deal links.

---

## Quick Start

### Step 1: Create a Project Folder
```bash
mkdir -p ~/funding-digest
```

### Step 2: Download the Template
Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

### Step 3: Start Working
```bash
cd ~/funding-digest
claude
```
Say: **"Generate a funding digest for fintech companies over the past two weeks"**

---

## Workflow Overview

| Step | What It Does |
|------|-------------|
| **Coverage & Period** | Establishes which sectors/companies to track and the time window |
| **Company Universe** | Builds and validates the entity list with S&P identifiers |
| **Funding Rounds** | Pulls round data with fallback strategies for empty results |
| **Analysis** | Identifies key trends, largest rounds, and notable investors |
| **PPTX Output** | Formats into a professional single-slide PowerPoint |

---

## Important Notes

- Uses nested skills for entity resolution -- subsidiaries have no funding rounds, so it resolves to parent companies automatically.
- The `role` parameter is critical when querying funding data -- investor vs. target company changes the results entirely.
- Empty results trigger fallback strategies (rephrased queries, broader date ranges) before reporting "no data."
- Requires S&P Capital IQ MCP server to be configured.
