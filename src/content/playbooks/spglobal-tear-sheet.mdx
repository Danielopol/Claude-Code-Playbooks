## What This Does

Generates professional company tear sheets using live S&P Capital IQ data via the Kensho LLM-ready API MCP server. Supports four audience types -- equity research, investment banking/M&A, corporate development, and sales/business development -- with each producing a differently structured one-pager. Works for both public and private companies.

---

## Quick Start

### Step 1: Create a Project Folder
```bash
mkdir -p ~/tear-sheets
```

### Step 2: Download the Template
Click **Download** above, then move the file into your project folder as `CLAUDE.md`.

### Step 3: Start Working
```bash
cd ~/tear-sheets
claude
```
Say: **"Generate a tear sheet for Stripe for our corporate development team"**

## Audience Types

| Audience | Focus Areas |
|----------|-------------|
| **Equity Research** | Valuation multiples, consensus estimates, earnings trends |
| **Investment Banking / M&A** | Enterprise value, deal comps, ownership structure |
| **Corporate Development** | Strategic fit, competitive positioning, acquisition rationale |
| **Sales / BD** | Company overview, decision makers, budget signals |

---

## Important Notes

- If the user does not specify an audience type, the skill will ask before proceeding.
- All derived metrics (EV/Revenue, margins, growth rates) are calculated with explicit intermediate steps and verified.
- Intermediate data files are saved to protect against context window compression.
- Output format is DOCX with professional formatting and consistent styling.
- Requires S&P Capital IQ MCP server and Kensho LLM-ready API MCP server to be configured.
