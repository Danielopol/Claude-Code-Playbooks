- **Builds the capture workflow** — Browser extensions, mobile capture, batch processing

## Troubleshooting

**Can't decide between tools**
Default to Notion if solo, Airtable if team-based, Google Sheets if you want zero learning curve.

**Database feels overwhelming**
Start with Quick Capture only (Title, URL, Pillar). Add the other fields gradually.

**Existing system is messy**
Ask Claude for a migration plan: "I have 200 bookmarks in Chrome. How do I move them into this new system?"
