## What This Does

This workflow enables precise extraction of tables from PDF documents using **camelot** - the gold standard for PDF table extraction. Handle complex tables with merged cells, borderless tables, and multi-page layouts with high accuracy.

---

## Quick Start

### Step 1: Create a Project Folder

```bash
mkdir -p ~/Documents/TableExtractor
```

### Step 2: Download the Template

Click **Download** above, then:
```bash
mv ~/Downloads/CLAUDE.md ~/Documents/TableExtractor/
```

### Step 3: Start Working

```bash
cd ~/Documents/TableExtractor
claude
```
