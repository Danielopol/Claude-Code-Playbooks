## What This Does

Render a terminal program's colored output to a PNG so Claude can actually see the visual result — color contrast, alignment, highlighting — instead of only reading raw ANSI escape codes.


## What's Inside

The template covers:

- **Why this exists**
- **The method: capture, then render**
- **Capture recipes per tool**
- **TUI programs (lazygit, htop, top) — out of scope**
- **Installing freeze (the preferred renderer)**
- **Bundled scripts**
