## What This Does

Checks the status of existing agreements with a vendor across all connected systems (CLM, CRM, email, documents, chat), compiles a consolidated view of the legal relationship, runs a gap analysis to identify missing agreements, and flags upcoming expirations or renewal deadlines.

---

## Quick Start

### Step 1: Download the Template

Click **Download** above to get the `CLAUDE.md` file.

### Step 2: Set Up Your Project

Create a project folder and place the template inside:

```
vendor-management/
├── CLAUDE.md
├── reports/         # Vendor status reports
├── agreements/      # Agreement copies
└── renewals/        # Renewal tracking
```

### Step 3: Start Working

```bash
claude
```

Say: **"Check all agreements with Acme Corp"**

## What Gets Checked

| Agreement Type | Status Tracked |
|---------------|---------------|
| **NDA** | Active, expired, pending |
| **MSA** | Terms, liability caps, governing law |
| **SOW** | Scope, deliverables, timeline |
| **DPA** | Data processing terms, compliance |
| **SLA** | Service levels, penalties |
| **Insurance Certificate** | Coverage, expiration |

---

## Gap Analysis

The assistant identifies what agreements are in place and what may be missing. For example, if there is an MSA but no DPA and the vendor handles personal data, that gap is flagged with a recommendation.

---

## Tips

- For vendor groups with multiple subsidiaries, specify whether you want to check a specific entity or the entire group
- Agreements approaching expiration within 90 days are highlighted prominently
- Expired agreements may still have surviving obligations (confidentiality, indemnification) -- these are flagged
