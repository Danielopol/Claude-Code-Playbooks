## What This Does

Defines the 12-step facilitation contract every interactive skill should follow: heads-up + entry mode picker, one-question-per-turn, progress labels, quick-select answers with multi-select parsing, decision-point recommendations only, interruption-safe flow, and best-guess assumptions tracking.

Pairs with all `*-workshop` and `*-advisor` skills as the source of truth for interaction behavior.

## The 12-Step Contract

| Step | Behavior |
|------|----------|
| 1 | Heads-up: time + question count |
| 2 | Entry mode picker (Guided / Context dump / Best guess) |
| 3-4 | One plain-language question per turn |
| 5 | Progress labels (Context Qx/N, Scoring Qx/N) |
| 6 | Follow-ups only when material |
| 7 | Numbered quick-select with "Other (specify)" + multi-select parsing |
| 8 | Recommendations ONLY at decision points |
| 9 | Accept numeric or custom; synthesize |
| 10 | Meta-question interrupt: answer + restate + resume |
| 11 | Stop/pause: halt + wait |
| 12 | End: summary + decisions + assumptions list |

---

## Tips & Best Practices

- **One question per turn.** Two = a wall of text.
- **Progress every turn.** "Q3/8" beats silence.
- **Recommendations only at decision points.** After every answer = interaction drag.
- **Parse loosely.** Accept "1", "#1", "1,3", "1 and 3", or free text.
- **Best-guess mode requires an Assumptions list.** Otherwise the user can't validate.

---

## Common Pitfalls

- Stacking multiple questions in one turn
- Numbered recommendations after every reply
- Cryptic shorthand instead of plain-language prompts
- No visible progress
- Ignoring multi-select or custom answers
- Best-guess outputs without "Assumptions to Validate"
